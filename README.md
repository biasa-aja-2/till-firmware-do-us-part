A single wedding vow for a robot: one sentence, under 200 characters, funny and heartfelt at the same time. The robot promises to stand by its partner in sickness and in software updates, and to love every version of them — including the buggy ones.

## Run it

```sh
python3 main.py
```

The program writes the vow to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), after checking it against the competition gate: UTF-8 text, 1–200 characters, a single sentence on a single line.
